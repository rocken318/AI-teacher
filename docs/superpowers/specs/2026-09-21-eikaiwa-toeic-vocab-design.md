# 英会話カテゴリー（TOEIC語彙）設計書

- 日付: 2026-09-21
- 対象: AI先生（`Y:\AI先生`）
- 概要: 学齢（小中高）とは独立した新カテゴリー「英会話」を追加し、その中に **英単語の問題集**（英→日の4択）を置く。レベルは学年ではなく **TOEICバンド**で段階化し、最終的に TOEIC800 相当まで積み上げる。**まずは v1 として「TOEIC500」バンドを3ユニット（約60語）**作る。**AIは使わない**（出題・採点・語義は authored 確定データ）。

## 1. 目的・方針
- 語彙力の土台を段階的に増強する問題集。学年に縛られない独立トラック（大人・高校生どちらも使える）。
- 既存のクイズエンジン（4択・index採点・答えはサーバー秘匿）を再利用し、**新規エンジンは作らない**（YAGNI）。
- 段階的に拡張: `TOEIC500 → 600 → 730 → 800`（v1は500のみ着手）。

## 2. データモデル（既存 quiz バンクを拡張）
- 新しい教科キー **`eikaiwa`**（表示ラベル「英会話」🗣️）を `Subject` / `SUBJECTS` に追加。
- レベルは `QuizUnit.grade` を **TOEICバンド文字列**として流用: `"TOEIC500"`（将来 `"TOEIC600"` 等）。`QuizGrade` 型にこれらのバンド値を追加する。
- ユニット構成: 1ユニット ≈ 20〜30語。各語が1 `QuizItem`。
  - `question`: 「〈英単語〉の意味は？」（例「achieve の意味は？」）
  - `choices`: 日本語の意味4つ（正解＋意味の近い/紛らわしい誤答3つ・重複空なし）
  - `answerIndex`: 0〜3に分散
  - `explanation`: 語義＋短い例文（例「達成する。例: achieve a goal（目標を達成する）」）
  - `choiceHints`: 任意（誤答の語がどういう意味かを添えると学習効果が高い）
- v1 ユニット（`TOEIC500`・約60語）:
  - `eikaiwa-500-1`（基礎動詞・約20語）
  - `eikaiwa-500-2`（基礎名詞/形容詞・約20語）
  - `eikaiwa-500-3`（ビジネス基礎語・約20語）
- 統合は既存の merge-by-id 機構（`quiz/index.ts` の `QUIZ_UNITS` に spread）。content-audit テストの不変条件を満たす。

## 3. 出題・採点（既存APIをそのまま使用）
- `/api/quiz/question`（unitId → 問題・選択肢を返す。答えは返さない）と `/api/quiz/grade`（unitId・itemId・choiceIndex → 正誤・解説）をそのまま使う。`eikaiwa` の unitId を渡すだけで動く。
- 記録: `recordAttempt(childId, "eikaiwa", unitId, correct)` でアクティブ子に保存（既存の childId 優先ロジック）。

## 4. 画面・導線
- **ホーム（HomeHub）に「英会話」カードを学齢に関係なく常時表示**（探究カードと同じ独立トラック扱い。`STAGE_SUBJECTS` には入れず、専用カードとして描画）。
- **専用ページ `/english`**（英会話ハブ）: TOEICバンドを選ぶ → その中のユニット一覧 → タップで4択練習（既存 `QuizPractice` 相当を流用、または `/learn/[subject]` を eikaiwa でも使えるよう一般化）。
  - 実装時に既存 `/learn/[subject]` が `eikaiwa` を受けられるか確認し、可能なら流用（バンドを学年セレクタに流用）。専用ページが必要ならその時に判断。
- 学齢テーマ（data-stage）に依存しない中立的な見た目でも、既存の意味トークンに合わせる。

## 5. 進捗
- v1 は「**記録＋ホームカードに問題数/正答率**」まで。
- **学齢ベースの制覇/全体%ダッシュボード（`/progress`）には含めない**。理由: `eikaiwa` の grade は `STAGE_GRADES`（小中高の学年）に属さないため、`stageTargetUnits` の対象に自動的に入らない（＝正しく除外される）。
- 将来: 英会話専用の到達度表示（バンド別の学習語数・正答率）を別途追加可能。

## 6. 段階（実装単位）
- **v1（本設計の対象）**: `eikaiwa` 教科追加＋`QuizGrade` にTOEICバンド追加＋`TOEIC500` の3ユニット（約60語）＋ホームカード＋導線。事実監査（語義・品詞・別解つぶし）。
- **v2以降**: TOEIC600/730/800 バンドを順次追加、日→英・例文空所補充の形式、英会話専用進捗ページ、（任意）リスニングや会話フレーズ。

## 7. 品質・非スコープ
- **AI不使用**。既存 Vitest／content-audit／tsc／build 緑を維持。
- 語彙は authored（人手/エージェント量産＋独立監査）。誤答は実在語で紛らわしく（造語ダミー禁止）、**別解成立を避ける**（1語1義に絞るか文脈で一義化）。正解位置は0〜3に分散。
- 非スコープ（v1）: 日→英、例文空所補充、リスニング、会話文、TOEIC600以上、専用進捗ページ、発音。

## 8. 検証観点
- `eikaiwa` 追加後も content-audit（id一意・answerIndex範囲・choiceHints整合）緑。
- ホームで学齢に関係なく英会話カードが出る／`/english`（または流用ページ）でTOEIC500の3ユニットが選べ、4択練習→採点→解説が動く。
- 記録がアクティブ子に入り、ホームカードに反映。制覇ダッシュボードには出ない（学年外）ことを確認。
- 3系統DB（Postgres/SQLite/Noop）で壊れない。
