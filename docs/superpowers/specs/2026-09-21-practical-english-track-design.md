# 実用英語トラック（英会話/TOEIC語彙の格上げ）設計書

- 日付: 2026-09-21
- 対象: AI先生（`Y:\AI先生`）
- 概要: 既存の英会話（TOEIC語彙）トラックを、学齢ピッカーの4つ目の選択肢「**実用英語**」に格上げする。選ぶとホームが"実用英語モード"になり、5教科とは**完全に別建ての進捗**を確認できる。**AIは使わない**（既存クイズエンジン・authored語彙を流用）。

## 1. 目的・方針
- 実用英語（TOEIC語彙）を学校教科と**別トラック**として明確に分ける。入口を学齢ピッカーに置き、独立トラック感を出す。
- 進捗を **5教科と混ぜない**（制覇%・全体%に絶対入れない）。
- **既存資産の再配置が中心**（新エンジン・新テーブルは作らない・YAGNI）。既存: `subject="eikaiwa"`、`grade="TOEIC500"…`、`EIKAIWA_UNITS`、`/learn/eikaiwa`、HomeHub の英会話カード。

## 2. モデル（"モード"として扱う。Stageとは別）
- 「実用英語」は学校の学齢(`Stage`=elementary/junior/senior)には**含めない**（テーマや `STAGE_GRADES` を汚さない）。
- 新しい記憶キー `ai-sensei-track-v1`（値 `"eikaiwa"` 等）を `src/lib/stage.ts`（or 新 `track.ts`）に追加。`getTrack()/setTrack()/clearTrack()`。
- 学齢ピッカー選択時に「実用英語」を選ぶと track=eikaiwa を記憶し、ホームを実用英語モードで描画。トグルで学校モード（小/中/高）へ戻る（track クリア）。
- テーマ(`data-stage`)は中立に流用（既定=小 の色、または実用英語用の控えめな指定）。学齢テーマの再スキンは無理に足さない。

## 3. 学齢ピッカー（StagePicker）
- 現状の 小学生/中学生/高校生 の**隣に「実用英語」ボタン**を追加（絵文字🗣️、コピー「TOEIC語彙を4択で」）。
- 「実用英語」選択 → `setTrack("eikaiwa")` → 学年ピッカーは出さず実用英語モードのホームへ（全学年から行ける必要はない＝これ自体が入口）。

## 4. ホーム（実用英語モード）
- 5教科カードは**出さない**。代わりに:
  - **TOEICバンド／単元一覧**（`unitsFor("eikaiwa", band)` を使う。当面バンドは `TOEIC500`。`/learn/eikaiwa?grade=TOEIC500` へ導線、または内包表示）。
  - **「実用英語の進捗」カード**（§5）。
  - ヒーロー/コピーは実用英語用（既存 `COPY.*.eikaiwaLabel`/`taglineEikaiwa` を活用）。
- 上部トグルで「学校の学習にもどる」（track クリア→学齢モード）。

## 5. 進捗（5教科と完全別建て）
- 実用英語専用の集計（既存 `eikaiwa` の `attempts` から）:
  - **TOEICバンド（＝unit）別の正答率／のべ問題数**、**全体の正答率／のべ**。
  - 表示は実用英語モードのホーム内カード＋（任意で）専用ページ `/progress/eikaiwa`。
- 集計は既存 `getChildProgress`（教科別 attempts/correct）から `eikaiwa` 分だけを取り出す、または eikaiwa 専用の軽い集計関数を足す（バンド別が要るなら unit 別集計を追加）。
- **5教科ダッシュボード(`/progress`)・制覇%・全体%には含めない**: eikaiwa の grade は `STAGE_GRADES` 外なので `stageTargetUnits` に自動的に入らない（既存の設計で除外済み）。加えて表示側（`groupSubjects` 等）でも eikaiwa を混ぜない（現状 5表示教科に eikaiwa は無いので既にOK）。
- v1は「バンド（単元）単位」。**「おぼえた語数（語＝item 単位の習得）」は将来**（item 単位の記録が入れば拡張。まちがいノート機能で item 記録が入るのでその後に連携可）。

## 6. データ・API
- 新テーブル不要。記録・採点は既存 `/api/quiz/{question,grade}` を流用（unitId=eikaiwa 単元）。`recordAttempt` の subject=`eikaiwa` のまま。
- 進捗表示用に、必要なら小さな集計（eikaiwa の unit 別正答率）を `progress-stats` 側 or 専用ヘルパーに足す。所有チェック等は既存 `/api/progress/*` と同方針（子の記録は childId 単位）。

## 7. 品質・非スコープ
- **AI不使用**。既存 Vitest／content-audit／tsc／build 緑を維持。モード切替・進捗集計の純ロジックはテスト。
- 非スコープ（将来）: 語単位の習得数、日→英・例文/リスニング、TOEIC600以上のバンド、実用英語の学齢別テーマ、まちがいノート連携。

## 8. 検証観点
- 学齢ピッカーに「実用英語」が出て、選ぶと実用英語モードのホーム（TOEICバンド＋実用英語進捗）になる。トグルで学校モードに戻れる。
- 実用英語の進捗が **5教科の `/progress`・制覇%・全体%に一切出ない**（混ざらない）。
- 実用英語で解いた記録が実用英語の進捗に反映され、5教科側には影響しない。
- 既存の学校モード（小/中/高）の見た目・挙動は不変。
